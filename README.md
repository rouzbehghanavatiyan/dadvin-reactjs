# دادوین

فرانت‌اند فارسی با React، Vite، Tailwind CSS و JSX، مطابق پوشه‌بندی nova.

## اجرا

```sh
npm install
npm run dev
```

ساخت خروجی: `npm run build` — پیش‌نمایش خروجی: `npm run preview`.

[راهنمای استقرار روی سرور و وضعیت قابلیت‌ها](DEPLOYMENT.md)

صفحات: `/login`، `/register`، `/forgot-password`، `/terms` و `/privacy`.

## ساختار

- `src/UI`: اجزای پایه مانند Btn، Input و Checkbox
- `src/components/auth`: اجزای کوچک فرم و پنل احراز هویت
- `src/layouts`: چیدمان مشترک
- `src/pages`: صفحات
- `src/hooks/slices` و `src/hooks/store`: وضعیت مشترک
- `src/services/index.jsx`: تبدیل داده فرم به قرارداد API
- `src/masterService.jsx`: انتقال درخواست و خطا
- `src/utils/axios.jsx`: نمونه مشترک Axios
- `src/routes` و پوشه‌های دیگر نمونه: محفوظ برای ادامه توسعه
- `public/assets/images/auth-office.png`: پس‌زمینه تصویری جدید

## بک‌اند

[راهنمای کامل اتصال و متن هماهنگی با بک‌اند](BACKEND-INTEGRATION.md)

آدرس سرور: `http://171.22.25.222:9090/`. در ۱۲ اکتبر ۲۰۲۶، APIهای ثبت‌نام و تأیید OTP منتشر و به نمونه مشترک Axios متصل شدند. تست زنده ارسال پیامک برای موکل و وکیل موفق بود؛ تأیید OTP در هر دو نقش با HTTP 500 و پیام «کاربری با این شماره یافت نشد.» شکست خورد. جزئیات در [گزارش تست](OTP-TEST-REPORT.md) آمده است. تا اصلاح بک‌اند، تأیید کامل ثبت‌نام تأیید نشده است.

ثبت‌نام شامل نام، نام خانوادگی، موبایل، ایمیل و کد ملی اختیاری و پروانه الزامی فقط برای وکیل است؛ پس از ارسال کد، فرم OTP نمایش داده می‌شود. قرارداد فعلی نقش داور را مشخص نمی‌کند؛ فرم این جریان فقط موکل و وکیل دارد. دکمه‌های ورود اجتماعی تا آماده‌شدن OAuth غیرفعال‌اند. ورود با رمز و گزینه مرا به خاطر بسپار هنوز API نشست ندارند. سیاست‌های حقوقی پیش‌نویس‌اند.

Vite مسیر محلی `/backend` را به سرور proxy می‌کند. مسیرهای ثبت‌نام و OTP طبق Swagger در `src/services/index.jsx` تعریف شده‌اند. endpointهای ورود با رمز و بازیابی در `.env` همچنان خالی هستند تا قرارداد واقعی آماده شود. برای production باید reverse proxy یا baseURL مبتنی بر HTTPS/CORS تنظیم شود.

## تست

`npm test` قرارداد دقیق DTO، تبدیل ارقام، ارسال null برای موکل، الزام پروانه برای وکیل، استفاده هر دو سرویس از Axios مشترک و تشخیص پاسخ ناموفق را بدون اتصال شبکه آزمایش می‌کند. `npm run build` خروجی تولید را می‌سازد. کدهای OTP و توکن در localStorage ذخیره نمی‌شوند.

## طراحی

طرح از تصویر مرجع کاربر الهام گرفته: پس‌زمینه آبی روشن، پنل دفتر حقوقی سرمه‌ای و فرم سفید. برند قابل‌نمایش فقط «دادوین» است. تصویر دفتر با ابزار داخلی ImageGen تولید شده؛ متن‌ها و کنترل‌های صفحه کامپوننت‌های واقعی React هستند. مشخصات تصویر در [یادداشت تصویر](IMAGE-ASSET.md) آمده است.
